# IQRA CAMPUS Website

Next.js (App Router) + TypeScript + Tailwind + Firebase. Bilingual (`/en`, `/bn`).

## Status
Phase 1–2 foundation: design base, official logos, URL-based localization, responsive header/footer, home hero, empty-state pages, Firebase init (no browser storage).

## Run
```
npm install
cp .env.example .env.local   # fill in Firebase values
npm run dev
```
Never commit `.env*` files, tokens or service-account files.
